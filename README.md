# Job Portal Web Application

A full-stack job portal web application developed using Python, Flask, SQLite, HTML, and CSS. The application provides a web-based platform for managing and displaying job-related information through a simple and user-friendly interface.

##  Project Overview

The Job Portal is a web application designed to provide a centralized platform for job-related information and management.

The project demonstrates the development of a database-driven web application using the Flask framework. It includes a Python backend, HTML templates for the user interface, static files for frontend styling, and SQLite for database management.

##  Features

- User-friendly web interface
- Job-related information management
- Database-driven application
- Backend development using Flask
- HTML templates for web pages
- Static files for frontend styling
- SQLite database integration
- Structured application architecture
